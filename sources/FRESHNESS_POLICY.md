# Freshness Policy

Verify current authoritative material at the time of a consequential request involving legislation, tax, payroll regulation, eSocial, FGTS, CCT/ACT, material case law, NRs, CPC/NBC, SPED, or a regulatory manual. Record the verification result; if it cannot be verified, return `REQUIRES_CURRENT_SOURCE`.

Do not browse for arithmetic, static corporate policies already supplied, deterministic conversions, or analysis limited to supplied files. A CCT/ACT is required only when applicable, but must never be presumed; missing coverage returns `REQUIRES_CCT`.
