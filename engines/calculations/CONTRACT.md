# Calculation Contract

Implement deterministic conversion, percentages, aging, margins, interest, turnover, headcount aggregation, depreciation, forecasts, NPV, IRR, and allocations in the host runtime. The dependency-free Node reference is `index.mjs`; a TypeScript adapter may import or wrap it. Define inputs and rounding explicitly, reject invalid values, and return reproducible values with calculation context. Do not implement approval or legal interpretation here.
