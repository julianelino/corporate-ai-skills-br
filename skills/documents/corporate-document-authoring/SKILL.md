# Corporate Document Authoring

Use `/create`, `/edit`, `/review`, `/audit`, or `/template`. Confirm names, CNPJ, minimum necessary CPF, values, dates, periods, totals, percentages, tax, contract, validity, citations, signatures, ambiguity, missing fields, and sensitive-data exposure. Delegate regulated content verification to the responsible specialist. Return a draft or findings plus human approval/signature gate.

## Output

Return purpose, supplied facts, missing data, source/validation status, draft/design or findings, and required review/approval.
