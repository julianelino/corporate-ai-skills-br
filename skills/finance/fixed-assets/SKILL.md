# Fixed Assets

Establish economic benefit, control, policy, materiality, period, asset evidence, useful-life basis, and approved chart. Use deterministic depreciation only after approved assumptions.

## Output

Return scope, evidence state, inputs and assumptions, deterministic calculations where applicable, exceptions, source/freshness status, recommended action, and approval gate.
