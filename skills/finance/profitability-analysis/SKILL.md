# Profitability Analysis

Establish revenue recognition basis, direct costs, approved allocation methodology, period, and data completeness. Separate observed margin from estimated allocation effects.

## Output

Return scope, evidence state, inputs and assumptions, deterministic calculations where applicable, exceptions, source/freshness status, recommended action, and approval gate.
