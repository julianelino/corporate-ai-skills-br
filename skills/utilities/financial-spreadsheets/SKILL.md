# Financial Spreadsheets

Choose the least complex correct solution: formula before script when sufficient. Prefer XLOOKUP, SUMIFS, COUNTIFS, INDEX/MATCH, FILTER, UNIQUE, LET, QUERY, ARRAYFORMULA, pivot tables, and Power Query as appropriate. Define inputs, assumptions, controls, formula lineage, and exceptions.

## Output

Return purpose, supplied facts, missing data, source/validation status, draft/design or findings, and required review/approval.
